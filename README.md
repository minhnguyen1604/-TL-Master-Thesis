# DTL-Master-Thesis

**Đề tài Luận văn Thạc sĩ:**  
*Các yếu tố ảnh hưởng đến phát triển hoạt động bảo lãnh ngân hàng cho khách hàng doanh nghiệp tại Ngân hàng Thương mại Cổ phần Công Thương Việt Nam (VietinBank).*

---

## 📂 DANH MỤC CÁC FILE TRONG DỰ ÁN

### 1. Báo cáo & Tài liệu Nghiên cứu
* **`Tong_Hop_Bao_Cao_De_Tai_Master_VietinBank.docx`**: File Word tổng hợp toàn bộ nội dung nghiên cứu, mô hình lý thuyết, xác định biến $Y$ và 6 biến độc lập $X$.
* **`Tong_Hop_Bao_Cao_De_Tai_Master_VietinBank.md`**: Bản xem trước Markdown của Báo cáo Đề tài Master.
* **`Tai_Lieu_Nghien_Cuu_Bao_Lanh_Ngan_Hang.md`**: Tổng hợp danh mục tài liệu tham khảo và link tải PDF các bài báo khoa học về bảo lãnh ngân hàng.

### 2. Thang đo & Phiếu khảo sát
* **`Phieu_Khao_Sat_Chinh_Thuc_VietinBank.docx`**: Mẫu Phiếu khảo sát chính thức 37 câu Likert 5 điểm chuẩn Word (dành cho Phương án 1 - Khảo sát Doanh nghiệp).
* **`Phieu_Khao_Sat_Chinh_Thuc_VietinBank.md`**: Bản xem trước Markdown của Phiếu khảo sát.

### 3. Ma trận Dữ liệu & Mẫu SPSS/Excel
* **`Ma_Tran_Hoi_Quy_11_Bien.csv`**: Ma trận Dữ liệu Hồi quy mẫu gồm 11 biến độc lập $X$ và 1 cột biến phụ thuộc $Y$ cuối cùng.
* **`Du_Lieu_SPSS_Hoan_Chinh.csv`**: Dữ liệu khảo sát mẫu gồm cả biến quan sát thô và các cột trung bình đại diện (`Mean`).
* **`Du_Lieu_Mau_Khao_Sat_SPSS.csv`**: Dữ liệu mẫu thô ban đầu.

### 4. Mã nguồn Python hỗ trợ
* **`create_survey_docx.py`**: Script sinh tự động file Word Phiếu khảo sát chuẩn định dạng.
* **`create_conversation_summary.py`**: Script sinh tự động file Word Báo cáo Đề tài tổng hợp.
